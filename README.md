# Esqueleto por el Sistema Solar. 

https://codesandbox.io/p/sandbox/ig-s6-forked-qsry5n

Proyecto interactivo desarrollado con **JavaScript y Three.js** que representa un sistema solar en 3D. Incluye el Sol, ocho planetas, varias lunas y los anillos de Saturno, todos ellos con sus propias texturas y movimientos orbitales. Además, se ha incorporado un personaje controlable por teclado. Atrapado en su nave, Marcelo se da cuenta de que el sistema solar ha encogido! O es él que se ha hecho más grande? Bueno, ya que estamos, nos podemos dar un paseo por el espacio que para eso vinimos. !Cuidado, no te choques! Aún no pasa nada, pero los planetas y el jugador tienen colisiones, en un futuro.... ¡puede que explotes!

## Para controlar al símpático personaje, usas las siguientes teclas:

| Tecla | Acción |
|---|---|
| `W` | Avanzar |
| `S` | Retroceder |
| `A` | Girar a la izquierda |
| `D` | Girar a la derecha |

Puedes utilizar el botón situado en la parte inferior de la pantalla para pausar o reanudar las órbitas planetarias. (Era una función de pausa para comprobar que había puesto bien las texturas pero me parece una buena opción interactiva así que se dejó.)

##  Tecnologías utilizadas

- **JavaScript:** lenguaje principal del proyecto.
- **[Three.js](https://threejs.org/):** biblioteca utilizada para crear y representar la escena 3D.
- **HTML y CSS:** estructura y estilos de los elementos de la interfaz.


**Proyecto desarrollado para explorar la creación de entornos 3D, animaciones e interacción mediante JavaScript y Three.js.**
